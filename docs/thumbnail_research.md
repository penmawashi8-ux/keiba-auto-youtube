# サムネイル研究（2026-11-20）

## 調べ方
- YouTube Data API で、競馬の予想・シミュレーション関連の10の検索語（マイルCS 予想、競馬 シミュレーション、競馬 AI 予想、競馬 3D レース など）を再生数順に検索した。2025年9月以降の218本が対象。
- 「再生数 ÷ チャンネル登録者数」を、サムネイルとタイトルで人を呼べたかの目安にした。登録者が少ないのに再生された動画ほど、サムネイルとタイトルが効いている。
- 自分のチャンネルの最新200本の再生数も取った。
- データは research-output の `sim/yt_research/`（videos.json、mine.json、thumbs/）にある。

## わかったこと
1. **シミュレーションはショート動画が強い。**
   - 登録者561人のチャンネルの「【宝塚記念 予想】AIが1000回シミュレーションした結果！！！」（34秒）が32万回再生された。同じチャンネルの安田記念版も8.6万回。
   - 登録者10〜200人台の「3Dで再現」ショートでも、1,500〜7,000回再生されている。
   - 中央値で見ると、ショートは再生数が登録者数の約5.9倍、長尺は約1.1倍だった。
2. **タイトルに「N回シミュレーション」が入ると強い。** 該当は4本で、再生数は登録者数の中央値で131倍。どれも小さなチャンネルだった。
3. **伸びている長尺のシミュレーション動画のサムネイルは、型がほぼ決まっている。**
   - 背景はレースの場面（ゲームのような3D映像）。
   - レース名を画面の半分ほどの大きさで、太い縁取りの極太文字にする。
   - 「枠確定後シミュレーション」「ChatGPT予想シミュレーション」のような短い帯を1本添える。
   - 年号を小さく入れる。
   - 例：登録者3.4万人のチャンネルで、宝塚記念が20万回、菊花賞が10万回。
4. **文字は少ないほうがいい。** 伸びている動画は、だいたい3〜4語以内。
   - 外部の調査（vidIQ）でも、1〜3語は効果があり、4語を超えると逆効果という目安が出ている。
   - 同じ調査では、顔の写真の効果はジャンルによって違った。
5. **答え（本命の馬名）を出すかどうかで、明確な差は見られなかった。**
   - 「本命」を含むタイトルは、再生数が登録者数の中央値で1.18倍。
   - 「この馬が倒します」のように馬名を伏せる型も、伸びている例がある。
6. **自分のチャンネル**
   - ニュースのショートは1本あたり約1,000回再生されている。
   - エリザベス女王杯のシミュレーション（長尺、写真＋「データの本命は」＋馬名＋勝率のサムネイル）は42回にとどまった。
   - 写真と文字の説明だけのサムネイルでは、シミュレーション動画だと伝わっていない可能性が高い。

## 方針
- **サムネイル**
  - 背景は CG のレース場面（ゴール前の馬群）にする。
  - レース名を極太の縁取り文字で大きく入れる。
  - 「1万回シミュレーション」の帯を1本入れる。
  - 下の一言は2案作る。A は「勝つのは…？」（答えを伏せる）、B は「勝率1位 12.9%」（数字を見せる）。
  - YouTube Studio の「テストと比較」で、2案を比べる。
- **タイトル**：「【マイルCS 2026】1万回シミュレーションした結果」の型にする（N回シミュレーションを先頭に）。
- **ショート版**：CG のレース部分を縦長（1080×1920）で描き直し、1分以内のショートも出す。研究ではここが一番伸びている。
