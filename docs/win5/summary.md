## 6. 回収率100%超えを目的にした検証（2026-11-07）

条件: 直前オッズは見られない前提（前日〜当日朝の購入）。

### やったこと
1. **予想人気モデル**: 出走前に分かる情報だけで最終的な支持率を予測（過去のオッズは正解ラベルとしてのみ使用）。実際の支持率との相関 0.92。
2. **WIN5の票の偏り**: log(的中票/総票) = 1.21 × Σlog(予想支持率) + 2.35（相関 0.90）。
   WIN5では人気馬に票が集中しやすく、人気薄の組み合わせほど配当が割高になる傾向。
3. **勝率の結合**: 勝率モデル4割＋予想人気6割（選抜用期間で推定）。締切前に出せる予測としては最良（log loss 2.026）だが、実際のオッズ（1.895）には遠く及ばない。
4. **期待回収率が基準値以上の組み合わせだけ買う戦略**: 期待値が高く見えるのは超大穴の組み合わせばかり（的中確率 1日0.01%程度）。93回では良し悪しを判定できない。

### 1レース単位での裏付け確認（数千レース・単勝の実回収率）
| 割安度（モデル÷予想人気） | 選抜用期間 | 最終評価期間 |
|---|---|---|
| 1.1〜1.2 | 90% | 70% |
| 1.2〜1.4 | 71% | 80% |
| 1.5以上 | 59% | 163%（大穴数頭の的中による） |
| 全馬（参考） | 72% | |

期間によって結果が逆転しており、**「割安」は偶然の範囲**。締切前に得られる情報では、市場を上回る精度は出せていない。

### 結論
- 現状のデータでは、**回収率100%超えを裏付けのある形で達成する方法は見つからなかった**。
- 確実に期待値が100%を超えるのは「**キャリーオーバーが売上の約3割を超える日**」だけ。ただし2026年の71回では発生ゼロで、まれ。
- 次の一手: 購入時点（前日夜〜当日朝）のオッズを今後毎週記録し、数か月分たまったら「購入時点のオッズ」を使った割安判定を検証する。

## 7. 朝オッズ（購入時点）を使った回収率重視方式（2026-11-08）

時系列オッズ: keibaodds.com（2025年1月以降、当日朝6〜7時〜最終）。購入時点＝当日10時までの最新オッズ。

- **勝率**: モデル＋朝オッズの結合（選抜用期間で推定）。人気薄の過大評価を補正し、最終評価期間で予測勝率と実際の勝率がほぼ一致（0.25%→0.26%、0.73%→0.70% など）。
- **WIN5配当の推定**: log(的中票/総票) = 1.30 × Σlog(朝オッズ支持率) + 3.38（最終評価期間でも相関0.93）。
  → **WIN5では人気馬に票が集中しすぎる**ため、人気薄を含む組み合わせが割安になりやすい。これが期待値の源泉。
